## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/rajawasthi-01/DSA-CPP.git
```

### 2. Open the folder

```bash
cd DSA-CPP
```

### 3. Compile a C++ program

```bash
g++ first.cpp -o first
```

### 4. Run the program

On Windows:

```bash
first.exe
```

Or:

```bash
.\first.exe
```

## 💻 Example

### Simple C++ Program

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;

    cout << "Enter a: ";
    cin >> a;

    cout << "Enter b: ";
    cin >> b;

    int sum = a + b;

    cout << "Sum = " << sum << endl;

    return 0;
}
```

### Output

```text
Enter a: 10
Enter b: 20
Sum = 30
```
